Glyphs

Glyphs are equipment composed of 3 different parts.

You will need one part of each type to create a glyph you can equip.

These parts define the condition, count and skill triggered by the glyph.

Part A: Condition

The part A of glyphs define a condition required for the glyph to "react".

  • Passivity: reacts each time the bearer is damaged.
  • Action: reacts each time the bearer attacks.
  • Defense: reacts each time the bearer guards.
  • Skill: reacts each time the bearer use a skill.
  • Power: reacts twice each time the bearer use an EX.
  • Impatience: reacts each time the bearer uses TP.
  • Greed: reacts each time the bearer ends the turn with HP under 50%.
  • Strength: reacts each time the bearer ends the turn with HP over 50%.
  • Destruction: reacts each time the bearer deals critical hits.
  • Speed: after hitting 5 times during the same turn, reacts after every hit.
  • Love: reacts each time the bearer heals allies.
  • Desire: reacts each time the bearer is healed.
  • Evasion: reacts each time the bearer dodges.
  • Restraint: reacts each time the bearer ends the turn with over 50 TP.
  • Wealth: reacts each time the bearer uses an item.

Part B: Count

The part B of glyphs define the count.

  • Featherlight: 3 reactions.
  • Light: 4 reactions.
  • Medium: 5 reactions.
  • Heavy: 6 reactions.

Part C: Skill
